Alias `py` for this repo
=========================

This repository provides a small helper so you can run `py` as a shortcut to `python3`.

- System alias (recommended): add the following to your shell config (e.g. `~/.bashrc`):

  alias py=python3

- Project helper (already added): run scripts from the repo root using:

  ./py main.py

Notes
- The alias is a convenience. The project still uses `python3` in scripts and docs.
- If you prefer the alias available in all shells, add the `alias` line to `~/.bashrc` or `~/.bash_aliases` and restart your terminal.
